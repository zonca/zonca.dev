healpy 1.20.0b1 is now available as a beta release on PyPI:

    pip install --pre healpy==1.20.0b1

The headline feature is `harmonic_ud_grade`, a new function to change map NSIDE through spherical-harmonic transforms instead of pixel averaging. Compared to `ud_grade`, it suppresses aliasing artifacts in the downgraded map by applying a bandlimit truncation with optional pixel-window and beam transfer corrections (based on Planck 2015 X, Eq. 1).

## Why harmonic_ud_grade?

The standard `ud_grade` averages child pixels into a parent pixel. This is fast but introduces aliasing artifacts — high-frequency power above the output Nyquist scale leaks into the downgraded map. For diffuse Galactic emission with a steep power spectrum (like dust), these artifacts can be significant.

`harmonic_ud_grade` decomposes the input map into spherical harmonics, truncates at the bandlimit appropriate for the output NSIDE, and synthesizes back. With the defaults (`pixwin=True`, `fwhm_out=0`), it also corrects for the pixel window function, providing cleaner power spectra than plain truncation.

For cases where you want additional smoothing to suppress Gibbs ringing from the sharp bandlimit cutoff, set `fwhm_out=None` to apply the effective resolution beam (Planck-scaled FWHM at the output NSIDE).

## Quick example

```python
import healpy as hp
import numpy as np

# Create a map at NSIDE 512
nside_in = 512
nside_out = 64
m = hp.synfast(np.ones(1000), nside_in, lmax=3*nside_in-1)

# Compare downgrade methods
m_pixel = hp.ud_grade(m, nside_out)
m_harmonic = hp.harmonic_ud_grade(m, nside_out)
```
